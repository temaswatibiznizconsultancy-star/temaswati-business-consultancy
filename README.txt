IMPORTANT BEFORE PUBLISHING
1. This is a static website starter. It is not published online yet.
2. The contact form prepares an email in the visitor's email app. It does not store or send form entries to a website server.
3. Check the email address and WhatsApp number before launch.
4. Confirm the legal wording with the actual company/trading-name arrangement. Current draft describes the consultancy as a proposed business division of Temaswati Group.
5. Service descriptions are administrative/document-preparation support and do not promise registrations, funding, tender awards, or other third-party outcomes.
6. Package prices are not shown because they should be confirmed before launch.
7. The design imports Montserrat from Google Fonts; if offline, the page falls back to Arial.
8. To preview, open index.html in a web browser. Keep all files together in the same folder.
9. To publish for free, a static host such as GitHub Pages can be used; you will need to create and configure your own account. A custom domain may cost extra.
